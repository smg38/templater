## Внутренности парсера

Плейсхолдер разбирается awk-скриптом в три этапа:

1. Регуляркой `\{\{[[:space:]]*[A-Za-z_][A-Za-z0-9_]*[[:space:]]*(\|[^{}]*)?\}\}`
   вырезается весь плейсхолдер из строки.
2. Из тела (`VAR | f1 | f2`) выделяется имя переменной и цепочка фильтров.
3. Цепочка фильтров применяется слева направо. `default(...)` учитывает
   вложенные скобки, `replace(...)` и `substr(...)` разбирают аргументы
   по запятой.

Значения берутся из `ENVIRON[]` — это безопасный доступ к переменным
окружения без `eval`.

### Условия

`{% if %}` обрабатывается **отдельным awk-проходом до** циклов и
плейсхолдеров. Это гарантирует:

- мёртвые ветви не вызывают внешние утилиты (`base64`, `sha256sum`) —
  важно для безопасности и производительности;
- вложенность `if`/`elif`/`else`/`endif` отслеживается стеком
  `if_stack[]`;
- `cond_eval` — рекурсивный спуск без `eval`: разбор `or`/`and`/`not`,
  скобок, операторов сравнения, `is defined`/`is empty`.

## Циклы

`{% for %}` / `{% endfor %}` обрабатываются до подстановки плейсхолдеров,
на уровне построчного прохода. Тело цикла накапливается в `for_body[depth]`,
затем разворачивается `N` раз; на каждой итерации `lv_set` кладёт текущее
значение итератора в `loop_val[]`.

При разборе `{{ ... }}` порядок такой:

1. `find_ph` находит **крайний левый** `{{` и его парный `}}`
   с учётом вложенности.
2. Внутри тела плейсхолдера разворачиваются вложенные `{{ VAR }}`
   (значения берутся из `loop_val[]` или `ENVIRON[]`).
3. Имя переменной ищется сначала в `loop_val[]`, потом в `ENVIRON[]`.
4. Применяются фильтры.

Это позволяет писать `{{ UUID_A_{{ user }} }}`: сначала `user` → `user1`,
затем `UUID_A_user1` → значение.

## Расширение фильтрами

Фильтр — функция `f_имя(v, arg)` в awk-скрипте:

```awk
function f_reverse(v,   i, r) {
    r = ""
    for (i = length(v); i >= 1; i--) r = r substr(v, i, 1)
    return r
}
```

И ветка в `apply_filter`:

```awk
if (name == "reverse") return f_reverse(v)
```

## Диаграмма потока

```
CLI args ──► getopts ──► envfiles[] ──► load each ──► export (если не задано)
                                       (последовательно, первое определение побеждает)
                │
                ▼
            template file (или stdin)
                │
                ▼
            awk: плейсхолдеры + фильтры
                │
                ▼
            outfile (или stdout)
```
