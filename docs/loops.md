# Циклы

## Синтаксис

```
{% for VAR in LIST %}
  ...{{ VAR }}...{{ OTHER }}...
{% endfor %}
```

- `VAR` — имя итератора (`[A-Za-z_][A-Za-z0-9_]*`);
- `LIST` — имя переменной окружения; её значение разбивается на элементы
  по одному или нескольким **пробелам, табам или `\r`**;
- тело цикла — всё между маркерами, включая многострочный текст.
- Внутри тела цикла можно использовать `{% if %}` (см.
  [conditionals.md](conditionals.md)). Вложенные `{% for %}` — по-прежнему
  не поддерживаются.

## Область видимости

Внутри тела доступны:

- `{{ VAR }}` — текущий элемент (можно применять фильтры);
- любые другие переменные окружения — как обычно;
- `{{ VAR }}` во вложенных `{{ ... }}` — см. «Динамические имена».

## Динамические имена переменных

Имя переменной может быть собрано из константной части и значения
итератора:

```jinja
uuid: "{{ UUID_A_{{ user }} }}"
```

Порядок разбора:

1. Внутренний `{{ user }}` подставляется первым (значение из loop-контекста).
2. Получившееся имя (`UUID_A_user1`) ищется в `ENVIRON[]`.

Работает для любого количества уровней вложенности, но на практике
хватает одного.

## Многострочное тело

```
{% for h in HOSTS %}
- host: {{ h }}
  env: {{ ENV }}
{% endfor %}
```

Каждая итерация выводит тело со своими значениями; между итерациями
автоматически вставляется `\n` тогда и только тогда, когда тело
содержит переводы строк.

## Пустой список

Если `LIST` пуст или переменная не определена — цикл даёт 0 итераций,
тело не выводится. Строки `{% for %}` и `{% endfor %}`, стоящие на
отдельных строках, также не выводятся.

## Ошибки

| Ситуация | Поведение |
|---|---|
| `{% for %}` без `{% endfor %}` | ошибка, выход с кодом 2 |
| `{% endfor %}` без `{% for %}` | ошибка, выход с кодом 2 |
| Некорректный `{% for X %}` | ошибка, выход с кодом 2 |
| Вложенные `{% for %}` | не поддерживаются |

## Примеры

### Список хостов

```jinja
servers:
{% for host in HOSTS %}
  - address: {{ host }}
    port: {{ PORT }}
{% endfor %}
```

```dotenv
HOSTS="alpha beta gamma"
PORT=8080
```

### Динамические ключи

```jinja
users:
{% for u in USERS %}
  - name: {{ u }}
    uuid: "{{ UUID_A_{{ u }} }}"
{% endfor %}
```

```dotenv
USERS="user1 user2"
UUID_A_user1="aaaa-1111"
UUID_A_user2="bbbb-2222"
```
