# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии: [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

## [3.3.3] - 2026-10-10
### Added
Ключ -e ENVFILE можно указывать несколько раз; файлы применяются
слева направо, побеждает первое определение переменной.

## [3.3.2] - 2026-10-10
### Fixed
- `render()` теперь корректно разворачивает вложенные плейсхолдеры
  (`{{ UUID_A_{{ user }} }}`) — сначала подставляется значение из
  loop-контекста, затем имя переменной ищется в `ENVIRON`.
- Строки, содержащие только `{% for %}` или `{% endfor %}`, больше не
  дают пустых строк в выводе.

## [3.3.0] - 2026-10-10
### Added
- Циклы `{% for VAR in LIST %} ... {% endfor %}`.
  Список — переменная окружения, элементы разделены пробелами/табами/`\r`.
  Внутри тела доступны все переменные и фильтры. Поддерживаются
  вложенные циклы.

## [3.2.0] - 2026-10-07
### Added
- Автопоиск `<template>.env` и автосоздание `<template>.out`.
- Фильтры: `upper`, `lower`, `trim`, `quote`, `urlencode`, `sha256`,
  `md5`, `hexdump`, `replace`, `substr`, `indent`, `b64decode`.
- Ключ `-e ENVFILE` для явной загрузки переменных.
- Ключ `-s` (strict) — ошибка на неопределённую переменную без `default`.
- Ключ `-o OUTPUT` для явного указания выходного файла.
- Поддержка `-` для чтения шаблона из stdin.

### Changed
- Полностью переписан парсер плейсхолдеров (awk вместо sed+eval).
- Убраны все `eval` — значения переменных больше не исполняются.

### Fixed
- Значения с `&`, `/`, `\`, `{}`, кавычками и переводами строк
  больше не портят подстановку.
- `default('hello world')` сохраняет пробелы.
- Несколько плейсхолдеров в одной строке обрабатываются корректно.

## [2.0.0] - 2021-XX-XX
### Added
- Первая публичная версия: `{{ VAR }}`, `default(...)`, `b64encode`.
